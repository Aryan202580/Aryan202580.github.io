## Publish on GitHub Pages
1. Upload `index.html` to the repository root.
2. Upload the complete `certificates` folder, preserving the file names and folder structure.
3. Commit the changes to the `main` branch.
4. Keep GitHub Pages set to `Deploy from a branch` → `main` → `/(root)`.
5. Visit https://aryan202580.github.io/ after deployment.

The LinkedIn link is set to https://www.linkedin.com/in/aryan-srivastava-599287282/.
Each certification card opens its corresponding PDF in a new tab. Keep all seven PDF files inside the `certificates` folder for the links to work.
