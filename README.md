# Aryan Srivastava — Personal Portfolio

A responsive dark premium personal portfolio designed for GitHub Pages. It uses plain HTML, CSS, and JavaScript, so no build step or package installation is needed.

## Publish at `https://aryan202580.github.io/`

1. Create a **public** GitHub repository named exactly `Aryan202580.github.io` under the `Aryan202580` account.
2. Upload `index.html` to the repository root.
3. Optional: add your resume PDF to the root and name it `resume.pdf` so the Download Resume button works.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then click **Save**.
6. Wait for deployment and open `https://aryan202580.github.io/`.

## Before sharing

- Replace the LinkedIn link in `index.html` with your exact LinkedIn profile URL.
- Confirm the HireView description matches what is implemented in your project.
- Check that the FleetLedger repository URL and Rental Billing links are correct and public where needed.
- This portfolio is public. Do not upload secrets, API keys, or private user data.
